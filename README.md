# PT CAN Lab — Petterson Tools

Página do analisador de rede CAN J1939 (PT-CAN-01), que conversa pelo **cabo USB** com o firmware `CAN_Lab_USB` (v1.9 ou mais novo; v2.0 para ECU › Mercedes) gravado no ESP32.

Abrir no **Chrome ou Edge do computador**: https://amarildo-cunha.github.io/CAN_Lab/ → **Conectar USB** → escolher a porta COM do ESP32.

- Feche o Monitor Serial do Arduino IDE antes de conectar (só um programa usa a porta por vez).
- A ligação é feita pelo Web Serial do navegador, a 921600 baud.
- Pode ser instalada como app (ícone na barra de endereço) e abre sem internet.

Só contém a página (sem firmware nem dados).
